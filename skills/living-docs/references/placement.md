# Placement

Prefer a place that runs (linter, types, test, review/verify checklist) over prose. Prefer **extend** an existing artifact over a new file.

| Intent | Prefer |
| --- | --- |
| Short principle / daily habit / decision guide | Project agent guide (`AGENTS.md`, `agents.md`, or equivalent) |
| Deep or path-scoped standing instructions | Project rules / instruction files the harness loads |
| Repeated mistake caught at review | Review / verify skill checklist step |
| Repeated “don’t do X” nothing can enforce | Anti-patterns topic file (prose fallback) |
| Step-by-step how-to with clear when | Skill `SKILL.md` |
| Distinct isolated review / specialist role | Harness subagent / launcher config (if any) |

Exact folders are project/harness-specific — use the project binding.
